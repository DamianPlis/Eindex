## ✨ Features Overview

This application is composed of several interconnected modules:

*   **📅 Scheduling & Planning:** Manages recurring and one-off appointments, allowing users to visualize their time effectively.
*   **✅ Deadlines Tracker:** Keeps users accountable with a dedicated module for setting, tracking, and viewing deadlines.
*   **🗺️ Planning View:** Offers a dedicated interface for complex planning cycles, separate from the main schedule.
*   **⚙️ Settings & Sync:** Integrates user settings and utilizes Firebase for reliable, real-time data synchronization across devices.
*   **🌍 Internationalization (i18n):** Supports multiple languages for a globally usable experience.
